⚡ El Evaluador

El corazón de CatCompiler. Aquí es donde el código cobra vida, la memoria se asigna y las matemáticas se resuelven.

¿Qué es el Evaluador?

El Parser nos entregó un Árbol (AST) que describe qué queremos hacer. El Evaluador es el motor que recorre ese árbol y ejecuta las instrucciones reales en la computadora.

Utiliza una función recursiva llamada Eval() que evalúa los nodos de abajo hacia arriba: primero resuelve los hijos, y luego usa esos resultados para resolver al padre.

1. El Sistema de Objetos (Los Valores)

En CatCompiler, todo lo que produce el Evaluador es un "Objeto". Cuando escribimos 5, el Parser lo ve como un nodo del árbol, pero el Evaluador lo convierte en un objeto Integer real en memoria.

Integer

Números

Representa valores enteros usando int64 de Go.

Value: 42
Boolean

Lógica

Representa verdadero o falso (true/false).

Value: true
Function

Funciones

Guardan parámetros, cuerpo y su Environment (Closures).

2. El Environment (La Memoria y Variables)

Para que existan las variables, necesitamos guardar nombres en la memoria de alguna forma. El Environment es básicamente un Diccionario (o Hash Map) que asocia un "nombre" (String) con un "valor" (Objeto).

let edad = 20;

Al ejecutar esto, el Evaluador llama a env.Set("edad", Integer(20)).

Llave (Nombre)Valor en Memoria (Objeto)
"edad"Integer{Value: 20}
"activo"Boolean{Value: true}
"sumar"Function{Params: [a, b], Body: ...}

🌍 Scopes (Alcance de Variables)

Si declaramos una variable dentro de un if o una función, no debería "ensuciar" las variables de afuera. Para esto, los Environments tienen un puntero "outer" (padre).

Cuando la función termina, su Environment "hijo" se destruye, pero el padre sigue intacto. Así se logra el Scope local.

3. ¿Cómo funciona Eval() paso a paso?

Veamos cómo el evaluador resuelve la expresión: 5 + 3

Eval( InfixExpression(+) )
↓ (Llama a evaluar la Izquierda)
Eval( IntegerLiteral(5) ) 👉 Retorna: Integer(5)
↓ (Llama a evaluar la Derecha)
Eval( IntegerLiteral(3) ) 👉 Retorna: Integer(3)
↓ (Suma ambos Objetos)
Resultado Final: Integer(8)

4. ¿Cómo Correr CatCompiler?

CatCompiler tiene dos formas de ejecutarse: de forma interactiva (REPL) o leyendo un archivo completo.

🕹️ Consola Interactiva (REPL)

Ideal para probar líneas rápidas de código.

$ go run main.go

Selecciona el modo de interacción:
1. Modo Lexer
2. Modo Parser
3. Modo Evaluador
Opción [1, 2 o 3]: 3

>> let x = 5 * 5;
>> x;
25

📄 Correr un Archivo (.limon)

Ideal para escribir programas grandes con ciclos, ifs y funciones matemáticas como Factorial o Fibonacci.

$ go run main.go main.limon

🐾 Ejecutando main.limon...
120

💻 Ejemplo Práctico: main.limon

Prueba crear un archivo main.limon con el siguiente código:

let factorial = function(n) {
  if (n == 0) {
    return 1;
  } else {
    return n * factorial(n - 1);
  }
};

// Evaluamos el factorial de 5
let resultado = factorial(5);

// El evaluador imprimirá el resultado de la última línea
resultado;
